# NOTE :) 비주얼 인덱스 보드 (HTML / CSS / JS)

제공된 디자인 이미지(main.jpg, modal.jpg, 무엇을 기록할까요? 팝업)를 바탕으로 제작된 반응형 비주얼 인덱스 보드 웹 애플리케이션입니다.

## 파일 구성
- `index.html`: 메인 구조 및 시맨틱 마크업, SVG 물결 필터, 모달 템플릿
- `style.css`: 부드러운 파스텔 라벤더/크림 톤앤매너, 물결 테두리 효과, 커스텀 세로 스크롤바, 숨김 가로 스크롤바, 반응형 레이아웃
- `app.js`: LocalStorage 데이터 영구 저장, 키워드/카드 생성·수정·삭제, 이미지 확대 모달, 텍스트 메모 읽기 모달, 마우스 휠 가로 스크롤

## 주요 기능
1. **NOTE :) 상단 고정**: 스크롤 시에도 헤더가 상단에 산뜻하게 고정됩니다.
2. **새로운 키워드 추가 (아래 +)**: 키워드(제목)를 필수로 입력해야 새 분류 행이 등록됩니다.
3. **자료 유형 선택 등록 (우측 +)**: 3번째 이미지 레이아웃을 바탕으로 링크, 텍스트, 이미지 중 선택하여 카드를 등록할 수 있습니다.
4. **모달 동작**:
   - 이미지: 클릭 시 thick periwinkle 프레임의 확대 모달(`modal.jpg`) 오픈
   - 링크: 클릭 시 새 탭으로 즉시 연결 (`window.open`)
   - 텍스트: 카드에는 제목만 깔끔하게 노출되고, 클릭 시 상세 본문 모달 오픈
5. **스크롤 디자인**:
   - 상하 스크롤: 둥근 알약형 슬레이트 블루 커스텀 스크롤바
   - 좌우 스크롤: 스크롤바는 깔끔하게 숨겨지며 마우스 휠 및 스와이프로 가로 스크롤 가능
6. **영구 저장 & 편집/삭제**:
   - 모든 데이터는 `localStorage`에 자동 저장됩니다.
   - 키워드 및 카드에 마우스를 올리거나 상단 '편집 모드'를 켜면 수정(연필) 및 삭제(휴지통) 버튼이 나타납니다.
